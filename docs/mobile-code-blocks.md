# 手机端代码块与长文本换行

文章的响应式样式位于 `assets/css/article-responsive.css`，由
`layouts/partials/common/extensions.html` 加载。所有规则只作用于
`.blog-content` 文章正文，且仅在视口宽度不超过 768px 时生效。
无需逐篇修改 Markdown，也不修改主题子模块。

## 处理方式

- `white-space: pre-wrap`：保留代码的原始换行、空格与缩进，同时允许显示时自动折行。
- `overflow-wrap: anywhere`：很长的英文标识符、路径、链接也能在必要时折行。
- `pre code` 改为块级元素；高亮行的内容设置 `min-width: 0`，避免内层布局撑宽代码块。
- 手机端代码字号为 `1.4rem`（当前主题下为 14px），行高为字号的 1.7 倍，内边距为 `1.4rem`。
- 段落、标题、列表和行内代码中的长文本也允许折行。
- 宽表格与复杂依赖图继续使用块内横向滑动，不强行压缩成窄列。
- 桌面端保留原有代码块样式和横向滚动。

这里的换行是 CSS 的“视觉折行”，不会在 Markdown 源文件中插入换行，
也不会改变代码元素中的文本内容。

## 后续调整

在样式文件中修改以下值即可统一调整所有文章：

```css
@media (max-width: 768px) { /* 手机/窄屏的生效范围 */
  /* pre 对应规则中： */
  font-size: 1.4rem;       /* 代码字号 */
  line-height: 1.7;        /* 行高倍数 */
  padding: 1.4rem;         /* 代码块内边距 */
}
```

以上是参数位置示意；实际修改时请编辑已有选择器中的属性。
若需要回到代码块不折行的行为，将 `pre` 规则中的 `white-space` 改为 `pre`。

本地预览时用浏览器的窄屏模式检查 320px、390px 与 768px，再切回桌面宽度检查。
发布仍需正常提交、推送并等待 GitHub Pages 部署成功。
